1. Deutsch–Jozsa: Is the hidden function constant or balanced?

For a one-bit input, a constant function gives the same output for both inputs; a balanced function gives different outputs. Under this promise, the ideal quantum algorithm distinguishes them with one oracle query.

2. Shor: Find factors using a repeating modular pattern

Shor’s quantum algorithm uses period finding. This teaching demo displays the modular arithmetic for a small example; the table itself is calculated classically, not by simulating a quantum circuit.

Select N and a, then calculate.

What does “mod” mean?

17 mod 5 = 2, because dividing 17 by 5 leaves remainder 2.

Why find the period?

The period r is the smallest positive integer for which ar mod N = 1. When suitable, r helps calculate non-trivial factors using GCD.

The displayed factor extraction is a simplified textbook demonstration. Shor’s full quantum algorithm estimates the period using quantum superposition and the Quantum Fourier Transform.

3. Grover: Search an unsorted list

Imagine one marked item hidden among equally likely choices. Grover’s algorithm uses an oracle and diffusion operation to amplify the marked item’s probability.

Iteration: 0   |   Target probability: 25.00%

Measurement probabilities

Grover steps: (1) Prepare equal superposition. (2) Oracle flips the target amplitude’s sign. (3) Diffusion reflects amplitudes about their mean. (4) Repeat an appropriate number of times, then measure.

The bars show the ideal state-vector simulation. The algorithm’s query complexity is O(√N), compared with O(N) for classical unstructured search. Too many iterations can reduce the target probability again.
