TOPIC 07

Particle in a 1D Box

Derivation of the wave function and quantized energy levels for a particle confined to a one-dimensional infinite potential well.

LEARN

Particle in a One-Dimensional Box

A simple model that demonstrates confinement and quantization of energy.

Physical Model

Consider a particle confined between two impenetrable walls separated by a distance L. The particle can move only along the x-axis inside the box.

Fig. 1: Infinite potential well for a particle in a one-dimensional box.

Inside the box: V = 0
Outside the box: V → ∞

Wave Functions and Probability Densities

The allowed wave functions of the particle are represented by different quantum states. The corresponding probability density is given by |ψₙ|².

Fig. 2: Wave functions and probability densities in a one-dimensional particle-in-a-box.

Remember: ψ describes the quantum state, while |ψ|² gives the probability density.

Boundary Conditions

  • At x = 0, ψ = 0.
  • At x = L, ψ = 0.
  • The particle cannot exist outside the box.
  • Therefore, the wave function must vanish at the walls.

Why is this Important?

The particle-in-a-box model demonstrates one of the most important ideas of quantum mechanics: a confined particle cannot possess arbitrary energy. Only certain discrete energy values are allowed.

DERIVATION

Complete Derivation

All steps remain visible for classroom explanation; there is no fading or automatic progression.

Step 1: Schrödinger Equation Inside the Box

For a particle inside the box, the potential energy is zero:

V = 0

The one-dimensional time-independent Schrödinger equation is

−(h²/8π²m)(d²ψ/dx²) + Vψ = Eψ

Since V = 0,

d²ψ/dx² + (8π²mE/h²)ψ = 0

Step 2: Standard Form

Put

k² = 8π²mE/h²

Then the equation becomes

d²ψ/dx² + k²ψ = 0

Step 3: General Solution

The general solution of this differential equation is

ψ(x) = A sin(kx) + B cos(kx)

Step 4: Apply the First Boundary Condition

At x = 0, the wave function must vanish:

ψ(0) = 0

Therefore

0 = A sin(0) + B cos(0) = B
Hence B = 0.

The wave function becomes

ψ(x) = A sin(kx)

Step 5: Apply the Second Boundary Condition

At x = L, the wave function must also vanish:

ψ(L) = 0

Therefore

A sin(kL) = 0

For a non-zero wave function,

sin(kL) = 0

Hence

kL = nπ
where n = 1, 2, 3, ...

Step 6: Allowed Wave Numbers

Therefore

k = nπ/L

Using k² = 8π²mE/h²,

n²π²/L² = 8π²mE/h²

Step 7: Quantized Energy

Solving for E gives

Eₙ = n²h²/(8mL²)
The energy is quantized. Only the discrete values corresponding to n = 1, 2, 3, ... are allowed.

Step 8: Normalized Wave Function

The normalized wave function for the particle in the box is

ψₙ(x) = √(2/L) sin(nπx/L)

where n = 1, 2, 3, ...

Final results: ψₙ(x) = √(2/L)sin(nπx/L) and Eₙ = n²h²/(8mL²).

ENERGY LEVELS

Quantized Energy

Energy is proportional to n² for a fixed box length and particle mass.

Eₙ = n²h²/(8mL²)

Thus

E₁ : E₂ : E₃ : E₄ = 1 : 4 : 9 : 16

First four energy levels

n = 1E₁ = E₁
n = 2E₂ = 4E₁
n = 3E₃ = 9E₁
n = 4E₄ = 16E₁

Ground state and zero-point energy

The lowest allowed state corresponds to n = 1. Therefore the minimum energy is

E₁ = h²/(8mL²)
The particle cannot have E = 0 while confined in the box. The lowest energy is finite and is called the zero-point energy.

Correct: A. Inside the ideal box, V = 0.

Correct: A.
